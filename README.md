# Alopo releases

Downloads for [Alopo](https://tryalopo.com/), a Mac app for practising spoken English with an AI that runs entirely on your Mac.

This repository holds only the app's release files. Get the app and the install guide at **[tryalopo.com](https://tryalopo.com/)**.

- Needs a Mac with Apple silicon, macOS 15 or later, and 16 GB of memory or more.
- Alopo is an early pilot and is not notarised by Apple yet. The [install guide](https://tryalopo.com/#install) shows how to approve it the first time you open it.
- Each release lists the SHA-256 of `Alopo.dmg`, so you can check your download with `shasum -a 256 ~/Downloads/Alopo.dmg`.
